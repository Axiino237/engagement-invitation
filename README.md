# Abinash & Menaka – Engagement Invitation

An interactive, mobile-first wedding engagement invitation website.

## Features
- **Royal Velvet Cover**: Interactive splitting card with golden medallion
- **Mandapam & Auspicious Hands Scene**: Festive oil lamps and traditional thamboolam presentation
- **Temple Gopuram Scene**: Cinematic parallax scroll with pure shining 24K gold typography
- **Event & Venue Details**: Add to Google Calendar, download `.ics`, and interactive map links
